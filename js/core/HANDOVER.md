# 인수인계 — 자양교회 유년부 사이트 데이터

다음 담당자(임원)가 읽을 문서입니다. 코드를 몰라도 됩니다.

## 한 줄 요약
- 사이트(https://jayangchild.github.io)는 **화면만** 있는 공개 저장소이고, 학생·선물 같은 **데이터는 비공개 저장소 `jayangchild-data`** 에 **암호화되어** 있습니다.
- 데이터를 여는 것은 **사이트 비밀번호**(선생님 모두 같은 것)이고, 그걸 잊었을 때 쓰는 것이 **복구 코드**입니다.
- 선생님들은 GitHub를 볼 일이 없습니다. 새 휴대폰은 이미 연결된 기기의 **QR**을 찍고 사이트 비밀번호를 넣으면 됩니다.
- PC를 켜 두지 않아도 사이트는 늘 동작합니다 (GitHub가 대신 보관).

## 꼭 넘겨받아 보관할 것 (5가지)

| 무엇 | 왜 필요한가 | 어디에 보관 |
|---|---|---|
| 1. **Gmail 계정** (GitHub 계정의 이메일) 아이디·비밀번호 | GitHub 비밀번호를 잊었을 때 되찾는 곳 | 인수인계 봉투 / 비밀번호 관리 앱 |
| 2. **GitHub 계정** `jayangchild` 비밀번호 | 토큰을 새로 만들 때만 씀 | 같은 곳 |
| 3. **GitHub 2단계 인증 설정 키**(OTP 앱에 넣는 긴 글자 또는 QR) + **GitHub 복구 코드**(recovery codes) | 휴대폰을 바꾸거나 잃어도 GitHub에 들어가기 위해. 이게 없으면 계정을 잃을 수 있음 | 종이에 적어 봉투에 |
| 4. **사이트 비밀번호** | 선생님들이 매번(또는 30일마다) 넣는 것 | 선생님들과 공유 |
| 5. **사이트 복구 코드** (예: `ABCD-EFGH-…` 24자) | 사이트 비밀번호를 모두가 잊었을 때 새 비밀번호를 정하는 유일한 방법 | 종이에 적어 봉투에. **선생님들과 공유하지 않음** |

- **사이트 비밀번호와 복구 코드를 둘 다 잃으면 아무도 데이터를 열 수 없습니다.** (GitHub 직원도 못 엽니다)
- GitHub 토큰은 따로 보관할 필요가 없습니다. 언제든 새로 만들 수 있습니다.

## 자주 하는 일

### 새 선생님 휴대폰 연결
1. 이미 쓰고 있는 기기에서 사이트 → 설정 → **새 기기 연결(QR)**.
2. 새 휴대폰 카메라로 QR을 찍고 열린 사이트에서 **사이트 비밀번호**와 이름을 넣습니다.
- QR 안의 연결 열쇠는 사이트 비밀번호 없이는 풀리지 않지만, 그래도 단체방에 올리지 말고 직접 보여 주세요.

### 사이트 비밀번호 바꾸기
- 설정 → 관리자용 → **비밀번호 바꾸기**. 데이터는 다시 암호화할 필요 없이 그대로입니다.
- 다른 기기들은 다음에 열 때 "비밀번호가 바뀌었어요"가 뜨고 새 비밀번호를 넣으면 됩니다.
- 그 기기에서 아직 올리지 못한 내용도 지워지지 않고, 새 비밀번호로 열면 올라갑니다.

### 모두 비밀번호를 잊었을 때
- 잠금 화면 → **비밀번호를 잊었어요**(복구 코드로 열기) → 복구 코드 + 새 비밀번호. 데이터는 그대로입니다.
- 다른 기기들은 새 비밀번호로 열면 됩니다.

### 복구 코드를 새로 받기 (예전 코드가 보였거나 봉투를 잃었을 때)
- 설정 → 관리자용 → **새 복구 코드**. 예전 코드는 그 자리에서 쓸 수 없게 됩니다. 새 코드를 종이에 적어 봉투에 넣으세요.

### GitHub 토큰 바꾸기 (만료되기 전에, 또는 1년에 한 번)
토큰은 사이트가 비공개 저장소를 읽고 쓰는 "연결 열쇠"입니다.
1. GitHub에 `jayangchild` 로 로그인 → 오른쪽 위 사진 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   - Token name: `jayangchild-site` + 날짜
   - Expiration: 가장 길게 (가능하면 1년). **만료일을 달력에 적어 두세요**
   - Repository access: **Only select repositories → `jayangchild-data`** 하나만
   - Permissions → Repository permissions → **Contents: Read and write** (나머지는 그대로)
2. 사이트 → 설정 → 관리자용 → **토큰 바꾸기** 에 새 토큰을 붙여 넣습니다.
3. 다른 기기들은 다음에 열 때 **저절로** 새 토큰으로 바뀝니다. 그래서 **예전 토큰은 1~2주 뒤에** GitHub 토큰 목록에서 지웁니다.
4. 그사이 한 번도 열지 않은 기기는 "연결 열쇠가 만료되었어요"가 뜹니다 → 연결된 기기의 QR로 다시 연결하면 됩니다. 그 기기에 남아 있던 내용도 지워지지 않고 올라갑니다.
- 토큰을 바꿔도 **데이터·사이트 비밀번호·복구 코드는 그대로**입니다.

### 선생님이 그만두셔서 확실히 막아야 할 때
1. 새 토큰을 만들어 **토큰 바꾸기** → **예전 토큰을 바로 삭제**.
2. **사이트 비밀번호 바꾸기**.
3. 남은 선생님들 기기는 QR로 다시 연결.
- 그만둔 분 휴대폰에 이미 받아 둔 예전 내용은 남을 수 있지만, 새 내용은 볼 수 없습니다.

### 휴대폰을 잃어버렸을 때
- "이 기기 기억"을 꺼 두었다면, 그 휴대폰은 사이트 비밀번호 없이는 데이터를 열 수 없습니다.
- "이 기기 기억"을 켜 두었다면 최대 30일 동안 비밀번호 없이 열릴 수 있습니다. 이때는 바로 위의 "확실히 막아야 할 때"를 하세요.
  그러면 새 내용은 막히지만, 그 휴대폰에 이미 받아 둔 내용은 그 기기 안에서 보일 수 있습니다.

## 지워지지 않는 것 (안심해도 되는 것)
- 사이트의 "삭제"는 모두 **휴지통**입니다. 휴지통에서 되살릴 수 있습니다.
- 두 선생님이 같은 때 같은 내용을 고치면 나중 것이 보이고, 다른 분이 고친 값은 "같은 때 고친 내용"으로 남습니다.
- 인터넷이 없을 때 저장한 것은 그 기기에 남아 있다가 연결되면 올라갑니다. 올리지 못한 내용이 있으면 "연결 끊기"가 되지 않습니다.
- GitHub에는 모든 저장의 **이력**이 남습니다.

## 하지 말 것
- `jayangchild-data` 저장소를 **공개(Public)로 바꾸거나 삭제하지 마세요.**
- 저장소의 `vault.json` 파일을 직접 고치거나 지우지 마세요. 이 파일이 망가지면 아무도 데이터를 열 수 없습니다.
- 사이트 비밀번호·복구 코드·토큰을 카카오톡 단체방이나 메일에 그대로 적지 마세요.
