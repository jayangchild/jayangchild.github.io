# 자양교회 유년부 사이트

유년부 선생님들이 함께 쓰는 사이트입니다. 지금은 **필사노트**(말씀카드 PPT/CSV 가져오기 → 달마다 디자인 → A4 필사지 인쇄)가 있고, 멤버·선물은 준비 중입니다.

- 주소: https://jayangchild.github.io (GitHub Pages — PC를 켜 두지 않아도 늘 열립니다)
- 데이터(말씀·디자인·그림)는 비공개 저장소 **`jayangchild/jayangchild-data`** 에 **암호화되어** 저장됩니다. 사이트 저장소에는 화면만 있습니다.
- 데이터를 여는 것은 선생님들이 함께 쓰는 **사이트 비밀번호**, 그걸 모두 잊었을 때 쓰는 것이 **복구 코드**입니다.
- 지우기는 모두 **휴지통**입니다(설정 → 휴지통에서 되살리기). 두 분이 같은 때 고친 것은 **⚠ 확인** 표시로 남아서 고를 수 있습니다.
- 인터넷이 없을 때 고친 것은 그 기기에 저장해 두었다가 연결되면 올립니다 (위 막대: 저장됨 / 올리는 중 / 오프라인 / 오류).

> 다음 담당자(임원)에게 넘길 때 읽을 문서: **[js/core/HANDOVER.md](js/core/HANDOVER.md)** — 무엇을 보관해야 하는지, 자주 하는 일.

## 처음 설정 (관리자가 한 번)

### 1. 데이터 저장소 만들기
GitHub에 `jayangchild` 계정으로 로그인 → 오른쪽 위 **+ → New repository**
- Repository name: `jayangchild-data`
- **Private** (꼭 비공개)
- 나머지는 그대로 (README 같은 파일도 만들지 않아도 됩니다) → **Create repository**

### 2. 토큰(연결 열쇠) 만들기 — Fine-grained token
1. 오른쪽 위 사진 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
   (바로 가기: https://github.com/settings/personal-access-tokens/new)
2. 이렇게 고릅니다.
   | 칸 | 고를 것 |
   |---|---|
   | Token name | `jayangchild-site` (만든 날짜를 붙여도 좋아요) |
   | Resource owner | `jayangchild` |
   | **Expiration** | 고를 수 있는 것 중 **가장 긴 것** — 목록에 *No expiration* 이 있으면 그것, 없으면 *Custom* 으로 1년 뒤 날짜 |
   | **Repository access** | **Only select repositories** → **`jayangchild-data`** 하나만 |
   | **Permissions → Repository permissions** | **Contents: Read and write**, **Metadata: Read-only** (자동으로 정해짐). 나머지는 모두 *No access* 그대로 |
3. **Generate token** → 나온 `github_pat_…` 을 복사합니다. (이 화면을 닫으면 다시 볼 수 없지만, 토큰은 따로 보관할 필요가 없습니다. 사이트가 암호화해서 보관하고, 잃어버리면 새로 만들면 됩니다.)
4. **만료일을 달력에 적어 두세요.**

### 3. 사이트에서 설정
1. https://jayangchild.github.io 를 엽니다 → **관리자(임원)용 → 처음 설정하기**
2. 토큰을 붙여 넣고, 토큰 만료일(또는 *만료 없음*)을 고릅니다.
3. **사이트 비밀번호**를 정합니다 (8자 이상, 선생님들이 함께 쓰는 것).
4. 내 이름을 넣고 **설정하기**.
5. **복구 코드**가 한 번만 나옵니다. 종이에 적거나 파일로 저장한 뒤, 확인 칸에 체크하고 **마지막 4글자**를 넣어야 다음으로 갑니다.
   - 복구 코드는 관리자만 보관합니다 (인수인계 봉투). 선생님들과 공유하지 않습니다.
   - **사이트 비밀번호와 복구 코드를 둘 다 잃으면 아무도(GitHub 직원도) 데이터를 열 수 없습니다.**
6. 이 브라우저에 예전(동기화 전)에 만든 필사노트가 있으면, 열 때 **자동으로 옮겨지고** 다 옮겨진 것을 확인한 뒤에만 예전 사본을 지웁니다.

### 토큰이 만료될 때
- 만료 2주 전부터 사이트 위에 "GitHub 토큰이 N일 뒤 만료돼요" 띠가 보입니다.
- 위 **2. 토큰 만들기**대로 새 토큰을 만든 뒤 사이트 → **⚙ 설정 → 관리자용 → GitHub 토큰 바꾸기** 에 붙여 넣고 새 만료일을 고릅니다.
- **데이터·사이트 비밀번호·복구 코드는 그대로**입니다. 다른 기기들은 다음에 열 때 **저절로** 새 토큰으로 바뀝니다.
- 예전 토큰은 1~2주 뒤 GitHub 토큰 목록에서 **Delete** 합니다. 그사이 한 번도 열지 않은 기기는 "연결 열쇠가 만료되었어요"가 뜨는데, 연결된 기기의 QR로 다시 연결하면 되고 그 기기에 남아 있던 내용도 올라갑니다.
- 이미 만료되어 **모든 기기**가 오류라면: 새 토큰을 만들고, 관리자 PC에서 **⚙ 설정 → 관리자용 → 토큰 바꾸기**(열려 있을 때) 또는 처음 화면의 **관리자용 → GitHub 토큰으로 이 기기 연결**(새 토큰 + 사이트 비밀번호)을 쓰면 됩니다. 그다음 다른 기기는 QR로 다시 연결합니다.

## 선생님 기기(휴대폰·PC) 연결하기
1. 이미 쓰고 있는 기기에서 **⚙ 설정 → 새 기기 연결 (QR) → QR 보여 주기**.
2. 새 휴대폰의 **카메라**로 QR을 찍고 뜨는 링크를 누릅니다.
3. 새 휴대폰에서 **사이트 비밀번호**와 **이름**을 넣으면 끝입니다.
- QR 안의 연결 열쇠는 사이트 비밀번호 없이는 풀리지 않지만, 그래도 **사진을 찍어 단체방에 올리지 말고** 직접 보여 주세요.
- QR을 못 찍으면 같은 곳의 **연결 링크 복사**로 본인에게만 보내고, 연결한 뒤 메시지를 지웁니다.
- **이 기기 기억하기(30일)** 는 기본으로 꺼져 있습니다. 나만 쓰는 휴대폰에서만 켜세요. 자리를 비울 땐 🔒(설정 → 잠그기).

| 백업 받기 | 백업 | 암호화 백업(그때의 비밀번호·복구 코드로 열림), 필사노트 백업(그림 포함, 암호화 안 됨 — 안전한 곳에만) |

- 시험
  - `node tools/serve.mjs` → http://127.0.0.1:8765/core-test.html?report (core 20개)
  - `npm i --no-save playwright-core` 후 `node tools/e2e.mjs` — 가짜 GitHub(core 의 `fake-backend.js`)로 두 기기를 헤드리스 Edge에서: 처음 설정 → 예전 데이터 옮기기 → CSV·PPTX → 그림 → QR 연결 → 오프라인 동시 수정 → 같아짐·충돌·휴지통 → 인쇄 미리보기(`pilsa/monthly.html` 과 비교). 화면 사진은 `tools/_tmp-e2e/`.
